# Contributing

Use Node >=22.13 and npm >=11.21.1. Install with npm ci, then run npm run check and npm run format:check. Keep transport code independent of frameworks and preserve external optional peers and declaration isolation. Add behavior-focused regression tests for fixes and include all framework/language consumers when changing public APIs. Do not add credentials to examples or fixtures. Use non-secret cache scopes and synthetic tokens in tests.

Changes to empty-response behavior, cache identity, authentication or origin rules require migration notes in CHANGELOG.md. Update the lockfile intentionally. Publish only after the release checks pass. Source and issues: https://github.com/Heshammesalam/universal-api-layer. Keep request return modes backwards compatible and test both scoped and explicitly broad native-query invalidation. Regenerate the versioned dependency inventory for releases, with its limited advisory scope documented.
