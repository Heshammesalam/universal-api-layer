# Security

The maintained release line is 0.7.x. Upgrade earlier versions for the cache identity, origin-boundary and cancellation fixes listed in CHANGELOG.md.

For a suspected vulnerability, contact the maintainer privately using the contact information on the npm package's maintainer profile: https://www.npmjs.com/package/universal-api-layer. Do not include real tokens, user records or private endpoints in public reports. Include a minimal synthetic reproduction, package/runtime versions and the impact. Source and tests are available at https://github.com/Heshammesalam/universal-api-layer. Public feature/bug reports belong in its Issues; do not post credentials or private vulnerability details there.

## Scope of security statements

Dependency checks report known advisories for the exact lockfile, selected install scope and time of execution. They do not constitute a complete code security audit or penetration test. Production-only audits of a consuming project do not establish assurance for a different package version or its development/peer dependency graph. The repository audit report records its version, UTC timestamp, runtime, npm version and lockfile digest. CI/test results and the historical code review are separate evidence, with the limitations documented in the README.
